# 📊 Advanced Data Science Lab — Assignments

A collection of **Advanced Data Science Lab (ADS)** assignments completed as part of the MCA curriculum at **Pimpri Chinchwad College of Engineering (PCCoE)**.

## 📚 Contents

### Assignment 01 — Data Analysis

Hands-on exercises covering:

* Python, Pandas & NumPy
* Data cleaning and missing-value handling
* Statistical analysis
* Data aggregation and pivot tables
* Matplotlib & Seaborn visualizations

### Assignment 02 — Streamlit Applications

Four interactive data-analysis applications:

* 🛍️ Retail Sales Dashboard
* 🎓 Student Test Analysis
* 🎬 Movie Ratings Explorer
* 🚢 Titanic Analysis

## 🛠️ Tech Stack

**Python | Pandas | NumPy | Matplotlib | Seaborn | Streamlit | Jupyter Notebook**
