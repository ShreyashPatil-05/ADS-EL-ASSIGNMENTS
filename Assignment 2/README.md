# 📊 ADS Assignment 2 — Experimental Learning

A consolidated multi-page **Streamlit** app covering 4 case study objectives for the Advanced Data Science Lab.

## Case Studies

| # | App | Dataset |
|---|-----|---------|
| 1 | 🛍️ Retail Sales Dashboard | `sales.csv` |
| 2 | 🎓 Student Grades Explorer | `grades.csv` |
| 3 | 🎬 Movie Ratings Explorer | `movies.csv` |
| 4 | 🚢 Titanic Survival Analysis | `titanic.csv` |

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

1. Push this repo to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repo, branch `main`, and set **Main file path** to `app.py`.
4. Click **Deploy**.
